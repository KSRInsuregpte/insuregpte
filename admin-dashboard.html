Protected operating rules

  • User upload never creates an Auth account and never changes a password or role.
  • New subjects must remain inactive until reviewed questions exist.
  • Upload parent records before child records by using the sequence in the Excel guide.
  • Entitlement upload cannot create or change payment and subscription access.
  • If any row fails, no row from that file is saved.
